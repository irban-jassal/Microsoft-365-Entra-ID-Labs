# Lab 2 - Conditional Access

## Objective
Create and validate a Conditional Access policy using Microsoft Entra ID.

## Scenario
The IT department requires all administrators to use Multi-Factor Authentication (MFA) when accessing Microsoft 365 services.

## Tasks Completed
- Created a Conditional Access policy
- Assigned the policy to a test administrator account (Alex Chen)
- Selected All resources
- Configured the Grant control to require MFA
- Enabled the policy in Report-only mode
- Reviewed Sign-in Logs to validate the policy

## Why Report-only?
Report-only mode allows administrators to evaluate the impact of a Conditional Access policy before enforcing it. This helps prevent accidental lockouts and reduces business disruption.

## Skills Practiced
- Conditional Access
- Multi-Factor Authentication (MFA)
- Report-only Mode
- Sign-in Logs
- Microsoft Entra ID

## Outcome
Successfully created and validated a Conditional Access policy following Microsoft best practices by using Report-only mode before enforcement.
