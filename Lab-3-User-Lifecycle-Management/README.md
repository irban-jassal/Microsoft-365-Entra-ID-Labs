# Lab 3 - User Lifecycle Management

## Objective
Practice common Microsoft Entra ID user administration tasks performed by IT administrators.

## Scenario
A new employee joins the organization and requires an account. Throughout the employee lifecycle, the account must be managed securely.

## Tasks Completed
- Created a new user (John Smith)
- Reset the user's password
- Blocked and re-enabled sign-in
- Deleted and restored the user account
- Added the user to a security group
- Assigned a Microsoft 365 license

## Skills Practiced
- User Administration
- Password Management
- Account Recovery
- Group Management
- Microsoft 365 Licensing

## Outcome
Completed the full user lifecycle from onboarding to offboarding, including account recovery and license management.
